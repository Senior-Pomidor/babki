# Настройка производственного календаря

## Текущая реализация

Приложение использует **официальные данные производственного календаря** из КонсультантПлюс в качестве fallback источника. Это обеспечивает точность и актуальность данных даже без внешних API.

### Источник данных
- **Официальный календарь**: [КонсультантПлюс 2025](https://www.consultant.ru/law/ref/calendar/proizvodstvennye/2025/)
- **Данные включают**: рабочие дни, праздники, переносы выходных, сокращенные дни
- **Статистика 2025**: 247 рабочих дней, 1972 рабочих часа, 4 сокращенных дня

## Опциональная настройка API Хантфлоу

Для получения данных в реальном времени можно настроить API Хантфлоу:

1. **Зарегистрируйтесь в Хантфлоу**:
   - Перейдите на https://huntflow.ru/
   - Создайте аккаунт или войдите в существующий

2. **Получите токен API**:
   - В личном кабинете перейдите в раздел "Настройки" → "API"
   - Создайте новый токен для доступа к API
   - Скопируйте полученный токен

3. **Обновите конфигурацию**:
   - Откройте файл `src/services/productionCalendar.js`
   - Замените `YOUR_HUNTFLOW_TOKEN` на ваш реальный токен:
   ```javascript
   const HUNTFLOW_API_TOKEN = 'ваш_токен_здесь'
   ```

## Возможности API Хантфлоу

Согласно [документации](https://huntflow.media/api-calendar/), API предоставляет:

### 1. Получение календарей для разных стран
- `GET /production_calendar` - список доступных календарей
- `GET /production_calendar/{calendar_id}` - информация о конкретном календаре

### 2. Получение нерабочих дней за период
- `GET /production_calendar/{calendar_id}/days/{deadline}` - нерабочие дни до указанной даты
- `POST /production_calendar/{calendar_id}/days` - массовый запрос

### 3. Расчет дат в будущем
- `GET /production_calendar/{calendar_id}/deadline/{days}` - дата через N рабочих дней
- `POST /production_calendar/{calendar_id}/deadline` - массовый расчет

### 4. Расчет дат в прошлом
- `GET /production_calendar/{calendar_id}/start/{days}` - дата N рабочих дней назад
- `POST /production_calendar/{calendar_id}/start` - массовый расчет

## Поддерживаемые страны

- **Russian Federation** (Россия)
- **Ukraine** (Украина)
- **Belarus** (Беларусь)
- **Kazakhstan** (Казахстан)

## Примеры использования

### Получение нерабочих дней за 2025 год:
```javascript
const response = await fetch('https://api.huntflow.ru/v2/production_calendar/1/days/2025-12-31', {
  headers: {
    'Authorization': 'Bearer YOUR_TOKEN',
    'Content-Type': 'application/json'
  }
})
```

### Ответ API:
```json
{
  "total_days": 365,
  "not_working_days": 118,
  "items": ["2025-01-01", "2025-01-02", ...]
}
```

## Преимущества API Хантфлоу

1. **Надежность** - стабильный сервис от крупной компании
2. **Актуальность** - регулярно обновляемые данные
3. **Множественные страны** - поддержка нескольких стран
4. **Гибкость** - различные методы для разных задач
5. **Производительность** - быстрые ответы API

## Fallback механизм

Если API Хантфлоу недоступен, приложение автоматически переключится на fallback данные с базовыми праздниками России.
